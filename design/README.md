# design/ · Fuente de diseño de Mostrame (v1.5)

| Archivo o carpeta | Qué es |
|---|---|
| `handoff.md` | Reglas completas de marca, interfaz, confianza, voz, journey e inventario. Leelo primero |
| `pantallas/` | Las 33 pantallas vigentes (PNG 2160×1350, ventana 1440×900, letra 1.2×) |
| `tokens.css` | Variables CSS: colores (solo claro), tipografía con escala, espacios, radios, foco, resaltado y movimiento |
| `tokens.json` | Los mismos tokens en JSON plano |
| `textos.es.json` | Textos finales por clave (es-UY / es-AR) |
| `referencia/` | `app.html` + `app.css` que generan las pantallas. Abrí `app.html?s=<clave>` (ver la tabla en el skill). Es referencia, no código de producción |
| `brand/` | Logo, símbolo, monocromos e ícono de app (SVG) |
| `icons/` | Íconos Lucide (SVG, licencia ISC) |
| `fonts/` | Fraunces y Atkinson Hyperlegible Next (woff2, licencia OFL) |

Los sitios que aparecen en las pantallas (`agenda.ejemplo.gub.uy`, `tiendamac.ejemplo.com.uy`) son ficticios.
